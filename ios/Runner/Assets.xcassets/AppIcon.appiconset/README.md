# App Icon Requirements for iOS

App Store için uygulama ikonları aşağıdaki boyutlarda olmalıdır:

- 1024x1024 px (App Store için)
- 180x180 px (iPhone @3x)
- 167x167 px (iPad Pro @2x)
- 152x152 px (iPad @2x)
- 120x120 px (iPhone @2x)
- 87x87 px (iPhone @3x)
- 80x80 px (iPad @2x)
- 76x76 px (iPad @1x)
- 60x60 px (iPhone @2x)
- 58x58 px (iPhone @2x)
- 40x40 px (iPhone @2x)
- 29x29 px (iPhone @2x)
- 20x20 px (iPhone @2x)

Not: Xcode'da Assets.xcassets/AppIcon.appiconset bölümüne ikonlarınızı sürükleyip bırakabilirsiniz.
